# CLI Expense Tracker

## Minimum Project Requirements

[https://roadmap.sh/projects/expense-tracker]
[ ] Users can add an expense with a description and amount.
[ ] Users can update an expense.
[ ] Users can delete an expense.
[ ] Users can view all expenses.
[ ] Users can view a summary of all expenses.
[ ] Users can view a summary of all expenses for a specific month (of current year).

### Nice to haves

[ ] Expense categories with filters
[ ] Users can set monthly budget and show a warning when user exceeds budget.
[ ] Users can export expenses to a CSV file.
